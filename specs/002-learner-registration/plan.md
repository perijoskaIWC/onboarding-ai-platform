# Implementation Plan: Learner Self-Registration

**Branch**: `002-learner-registration` | **Date**: 2026-05-26 | **Spec**: [spec.md](spec.md)

## Summary

Add self-registration for learners. One new backend endpoint (`POST /api/auth/register`), one updated frontend page (`Login.jsx` with sign-up toggle), and one new frontend service function. No database migrations, no new models, no new routers.

## Technical Context

**Language/Version**: Python 3.11 (backend), React 18 / Node 20 (frontend)

**Primary Dependencies**: FastAPI, SQLModel, passlib[bcrypt], pydantic[email] — all already installed

**Storage**: PostgreSQL — existing `users` table, no schema changes

**Testing**: Manual flow testing via browser

**Target Platform**: Linux container (Podman Compose), modern browsers

**Project Type**: Full-stack web application — additive change to existing system

**Performance Goals**: Registration completes in under 2 seconds

**Constraints**:
- Role MUST be assigned server-side only — never accept from request body
- Password MUST be hashed with bcrypt before storage
- Duplicate email MUST return 409, not 500
- Successful registration MUST auto-login (return tokens, no separate login step)

**Scale/Scope**: Same as parent platform — ~50 concurrent users

## Implementation Phases

### Phase 1: Backend — Register Endpoint

Add to `backend/app/api/auth.py`:

- Pydantic schema `RegisterRequest` with `email: EmailStr` and `password: str` (min_length=8)
- `POST /api/auth/register` handler:
  1. Check for existing user with same email → 409 if found
  2. Hash password with `hash_password()`
  3. Create `User(email=..., hashed_password=..., role="learner")`
  4. Commit to DB
  5. Issue access token + set refresh token cookie (reuse logic from login)
  6. Return 201 with `{"access_token": ..., "token_type": "bearer"}`

### Phase 2: Frontend — Auth Service

Add to `frontend/src/services/auth.js`:

```js
export const register = (email, password) =>
  api.post('/auth/register', { email, password })
```

### Phase 3: Frontend — Login Page Toggle

Modify `frontend/src/pages/Login.jsx`:

- Add `mode` state: `'login' | 'register'`
- Show sign-up form when `mode === 'register'`: email, password, confirm-password fields
- Client-side validation: passwords match check before submit
- On successful register: store `access_token`, redirect to `/learner`
- Toggle link: "Don't have an account? Sign up" / "Already have an account? Sign in"
