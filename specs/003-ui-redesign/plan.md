**Branch**: `003-ui-redesign` | **Date**: 2026-05-26 | **Spec**: [spec.md](spec.md)

## Implementation Phases

### Phase 1: Sidebar Fix (Blocker)

The learner sidebar has hardcoded `/learner/projects/1/...` links. The correct pattern: learners navigate to their project from the dashboard; project-level navigation (Learning Path, AI Tutor, Quiz, Progress) lives as tabs inside the project page.

**Change `Sidebar.jsx`**: Remove all project-specific learner links. Keep only `{ to: '/learner', label: 'Home' }` for the learner role.

### Phase 2: Admin Project Detail Tabs

Replace the long vertical scroll in `ProjectDetail.jsx` with a 4-tab layout:

```
[ Documents ] [ Learning Path ] [ Quiz ] [ Learners ]
```

- Tab bar: `border-b border-gray-200` row of buttons
- Active tab: `border-b-2 border-brand-600 text-brand-600 font-medium`
- Inactive tab: `text-gray-500 hover:text-gray-700`
- State: `const [tab, setTab] = useState('documents')`

All existing logic (polling, upload, Regenerate, assign learner) stays unchanged — only JSX structure changes.

### Phase 3: Learner Project Tab Page

Add `frontend/src/pages/learner/LearnerProject.jsx` with 4 inline tabs:

```
[ Learning Path ] [ AI Tutor ] [ Quiz ] [ Progress ]
```

Each tab renders the existing page component's content inline. Add route to `App.jsx`:

```jsx
<Route path="/learner/projects/:projectId"
  element={<LearnerLayout><LearnerProject /></LearnerLayout>} />
```

Update `Dashboard.jsx` project card links to `/learner/projects/:id`.

### Phase 4: Visual Polish — Skeletons & Empty States

**Skeleton pattern** (replaces all "Loading…" text):
```jsx
<div className="space-y-3 animate-pulse">
  <div className="h-4 bg-gray-200 rounded w-3/4" />
  <div className="h-4 bg-gray-200 rounded w-1/2" />
</div>
```

**Empty state pattern** (replaces "No X yet" plain text):
```jsx
<div className="text-center py-12">
  <svg className="mx-auto h-10 w-10 text-gray-300" .../>
  <h3 className="mt-2 text-sm font-semibold text-gray-900">No documents yet</h3>
  <p className="mt-1 text-sm text-gray-500">Upload a .txt or .md file to get started.</p>
  <button className="mt-4 bg-brand-600 text-white px-4 py-2 rounded-md text-sm hover:bg-brand-700">
    Upload
  </button>
</div>
```

Apply to: admin Projects list, admin ProjectDetail tabs, learner Dashboard, learner LearningPath.

### Phase 5: Colour Consistency

Audit all `blue-600`, `blue-700`, `blue-500` across all JSX files. Replace with `brand-600`, `brand-700`, `brand-500`. Keep `red-*` for errors and destructive actions.

Standard button: `bg-brand-600 text-white px-4 py-2 rounded-md text-sm font-medium hover:bg-brand-700 disabled:opacity-50 transition-colors`

### Phase 6: Login Page Polish

- Input focus ring: `focus:ring-brand-500`
- Submit button: `bg-brand-600 hover:bg-brand-700`
- Card shadow: `shadow-lg`

## No Data Model or API Contract Changes

Frontend-only. No new endpoints, no schema changes, no migration needed.
